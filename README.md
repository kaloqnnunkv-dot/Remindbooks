# ReMindBooks v2.0

Онлайн книжарница на български език: физически книги с доставка, PDF книги,
аудио съдържание, блог, потребителски профили и пълен административен панел.

Изградена по техническата спецификация `ReMindBooks_v2_Tehnicheska_Dokumentacia.pdf`.

---

## Технологии

| Слой | Технология | Защо |
| --- | --- | --- |
| Framework | Next.js 15 (App Router) | Едно приложение — фронтенд и бекенд заедно |
| Език | TypeScript (strict) | Грешките се хващат при компилация, не в production |
| Стилове | Tailwind CSS v4 | Темата е дефинирана като CSS променливи в `globals.css` |
| База данни | PostgreSQL + Prisma | Релационен модел с миграции |
| Автентикация | Auth.js v5 (NextAuth) | Парола + Google, JWT сесии |
| Плащания | Stripe Checkout | Не докосваме данни на карти — по-малко отговорност |
| Файлове | S3-съвместимо (R2/S3/MinIO) | PDF и аудио се сервират от CDN, не от сървъра |
| Имейли | Resend (HTTP API) | Работи без SMTP порт, съвместимо с всеки хостинг |
| Бюлетин | MailerLite | Според спецификацията |

Без излишни зависимости: няма UI библиотека, няма state manager, няма ORM
надстройки. Иконите са вградени SVG.

## Бърз старт с Docker

Най-бързият начин да видите сайта — не изисква Node.js или PostgreSQL:

```bash
docker compose up -d --build              # http://localhost:3000
docker compose --profile seed run --rm seed   # начални данни
```

Вход в админ панела: `admin@remindbooks.com` / `ReMind2026!`

Подробности и вариант за разработка с горещо презареждане: **[DOCKER.md](./DOCKER.md)**

## Бърз старт без Docker

```bash
# 1. Зависимости
npm install

# 2. Конфигурация
cp .env.example .env
#    Попълнете минимум: DATABASE_URL, AUTH_SECRET, NEXT_PUBLIC_APP_URL
#    AUTH_SECRET се генерира с:  openssl rand -base64 32

# 3. База данни
npm run db:push      # създава таблиците
npm run db:seed      # начални данни + администраторски профил

# 4. Стартиране
npm run dev          # http://localhost:3000
```

След `db:seed` в конзолата се изписват данните за вход в админ панела.
**Сменете паролата веднага след първия вход.**

Приложението стартира и без Stripe, S3 и имейл ключове — съответните функции
просто са изключени. Това позволява да се работи по съдържанието, преди
клиентът да е отворил всички акаунти.

## Важни решения при изграждането

**Плащането се потвърждава само от webhook-а.** Страницата за успех
(`/checkout/uspeh`) не променя статуса на поръчката — всеки може да отвори този
URL ръчно. Наличностите намаляват и дигиталното съдържание се отключва
единствено в `/api/webhooks/stripe`, след проверка на подписа на Stripe.
Функцията `fulfillOrder` е идемпотентна: Stripe доставя събития по няколко пъти
и повторното изпълнение не бива да намалява склада двойно.

**Цените никога не идват от клиента.** Кошницата в cookie пази само
идентификатори и количества. Всички суми се преизчисляват от базата при всяко
показване и при финализиране на поръчката.

**Файловете не са публични.** PDF и аудио се сервират през endpoint-и, които
проверяват дали потребителят притежава продукта (`Entitlement`) или има валиден
гост токен от имейла. Ключовете в хранилището не достигат до браузъра.

**Цените са в стотинки (Int).** Изчисления с плаваща запетая върху пари водят
до грешки от по една стотинка, които се натрупват.

**Продукт с направени поръчки не се изтрива, а се скрива.** Иначе историята на
поръчките би загубила смисъл. Същото важи за промо кодовете.

**Данните в поръчката са снимка (snapshot).** Заглавието и цената се копират в
`OrderItem`, за да останат верни и след промяна на продукта.

## Функционалности по избор

Изключват се с променливи на средата, без промяна в кода:

```bash
FEATURE_COD="false"             # наложен платеж
FEATURE_REVIEWS="false"         # ревюта и оценки
FEATURE_GIFT_CARDS="false"      # подаръчни карти
FEATURE_BLOG_COMMENTS="false"   # коментари в блога
```

Входът с Google се активира автоматично при наличие на `GOOGLE_CLIENT_ID`.

## Тема

Дизайн токените са в `src/app/globals.css` — топла хартиена палитра, копирана
от 21st.dev. Промяната на цвят става на едно място:

```css
:root {
  --primary: #a67c52;      /* акцентен цвят */
  --background: #f5f1e6;   /* фон */
  --foreground: #4a3f35;   /* основен текст */
}
```

Тъмната тема е дефинирана в `.dark` и е готова за използване, ако бъде добавен
превключвател.
